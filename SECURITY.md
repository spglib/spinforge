# Security policy

## Supported versions

Security fixes are provided for the latest release series and the current
`main` branch.

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| < 1.0 | No |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/spglib/spinforge/security/advisories/new)
to share a description, reproduction steps, affected versions, and any known
mitigation. If the private reporting form is unavailable, email the maintainer
at kshinohara0508@gmail.com.

The maintainers will acknowledge the report when it is reviewed and will
coordinate disclosure and a fix as appropriate. No fixed response-time service
level is promised.
